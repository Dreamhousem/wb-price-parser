# WB Price Monitor — Single Mode (1 user)

Это **single-user** версия мониторинга цен Wildberries с уведомлениями в Telegram.
Она рассчитана на **одного пользователя (меня)** и поэтому хранит данные в простых **JSON-файлах**.

> Ветка: `singlemode`  
> Для версии на несколько пользователей (с SQL) см. ветку: `multimode`

---

## Что умеет

- Отслеживает цены по списку подписок (товары WB)
- Периодически проверяет изменения и отправляет уведомления в **Telegram**
- Хранит подписки и состояние проверок в **JSON** (папка `data/`)

---

## Отличия от Multi Mode

| Пункт | Single Mode (`singlemode`) | Multi Mode (`multimode`) |
|---|---|---|
| Пользователи | 1 (личное использование) | много пользователей |
| Хранилище | JSON (`data/*.json`) | SQL база данных |
| Сложность | проще | сложнее, но масштабируется |
| Цель | быстро “для себя” | развитие проекта под мульти-юзеров |

Остальная логика максимально похожая: подписки → проверка → уведомления.

- Python 3.10+ (или выше)

## Быстрый старт (Linux / WSL / Ubuntu)

### 1) Клонируй проект и перейди на ветку `singlemode`

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd wb_price
git switch singlemode
```

### 2) Создай и активируй виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Проверка (должны указывать на `.venv`):

```bash
which python
which pip
```

### 3) Установи зависимости

```bash
pip install -r requirements.txt
```

---

## Настройка Telegram

### 1) Создай бота и получи токен
1. Открой @BotFather
2. Команда: `/newbot`
3. Сохрани токен вида `123456:ABC-DEF...`

### 2) Узнай свой Chat ID
Самый простой способ — бот типа @userinfobot (или любой аналог), который покажет твой `chat_id`.

### 3) Передай токен и chat_id приложению

**Вариант A: переменные окружения (удобно для Linux/WSL)**

```bash
export TG_BOT_TOKEN="ВАШ_ТОКЕН"
export TG_CHAT_ID="ВАШ_CHAT_ID"
```

> ⚠️ Если в коде используются другие имена переменных — замени их на свои
> (ориентируйся на то, откуда проект читает конфиг).

**Вариант B: файл `.env` (если у тебя так устроено)**  
Создай файл `.env` (и добавь его в `.gitignore`), например:

```env
TG_BOT_TOKEN=ВАШ_ТОКЕН
TG_CHAT_ID=ВАШ_CHAT_ID
```

## Хранилище данных (JSON)

Single Mode хранит данные в папке `data/`:

- `data/subscriptions.json` — список подписок
- `data/state.json` — состояние последней проверки (чтобы понимать, что изменилось)

> Совет: если репозиторий публичный — **не храни личные подписки** в коммитах.  
> Лучше держать `*.example.json` в репо, а реальные `data/*.json` игнорировать через `.gitignore`.

### Пример структуры subscriptions.json (пример/шаблон)

Ниже — примерный шаблон (подстрой под фактический формат в твоём проекте):

```json
[
  {
    "product_id": 12345678,
    "title": "Пример товара",
    "target_price": 199.99,
    "enabled": true
  }
]
```

Если формат в проекте другой — ориентируйся на код, который читает/пишет подписки.
